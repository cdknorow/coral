Coral

Run Claude Code, Codex, Gemini CLI, and Pi.dev as a coordinated engineering team on one codebase — without losing visibility or control.

This site has moved on from the Python version of Coral.

Coral is now a Go application distributed as a native binary. The old pip install agent-coral instructions that used to live here installed the Python implementation, which is no longer maintained.

If you ever ran that pip command, uninstall it before installing Coral. The two share command names, the ~/.coral data directory, and port 8420. With both installed, typing coral can silently start the old Python version instead — it will look like it worked.

# do you have both? more than one hit means yes
which -a coral coral-board launch-coral

# remove the retired Python package
pip uninstall agent-coral

One thing that trips people up: the Python releases reached 4.4.1 on PyPI. The Go rewrite restarted versioning at 1.0.0, so the current v1.0.8 is newer than 4.4.1, not older.

Coral is a local server that runs multiple CLI coding agents in parallel on the same repository. Each agent runs in its own terminal session, agents coordinate through a shared message board, and you watch and steer all of them from one browser tab.

You bring your own agents and API keys. Coral has no API keys of its own and never calls a model on your behalf. It runs the CLI agents you have already installed, using your credentials. To count tokens and costs, Coral can proxy those agents' API traffic locally — the traffic goes to the same provider it always did, and none of it comes to us.

Coral itself does send anonymous usage events. A fixed list — installed, opened, agent launched, team launched, task completed, and a few more — each carrying only Coral's version and build, your operating system and CPU architecture, tied to a random ID. Never your prompts, your code, repository or file names, agent output, personal information, or licence key. There is no opt-out switch. Builds you compile yourself carry no analytics key and send nothing at all, and the whole implementation is in internal/tracking if you would rather read it than take our word.

Requirements

  • tmux — the default session backend on macOS and Linux
  • At least one CLI coding agent installed: Claude Code, Codex, Gemini CLI, or Pi.dev

Install

Download the latest release from GitHub Releases:

  • macOS — Coral.v<version>.dmg (universal binary), e.g. Coral.v1.0.8.dmg
  • Linux — coral-linux-amd64-<version>.tar.gz, e.g. coral-linux-amd64-1.0.8.tar.gz

Coral is free. No purchase or account is required to download or use it.

Build from source

Requires Go.

git clone https://github.com/cdknorow/coral.git
cd coral/coral-go
make build

Run

macOS — open Coral.app. Linux — run ./coral from the extracted tarball. Source build — the binary lands in bin/, so run ./bin/coral.

Either way, open http://localhost:8420 and click +New to launch your first agent or create a team.
