This page is gone

You followed a link to documentation for the Python implementation of Coral, which is no longer maintained. Those pages have been removed rather than left up, because they described software we no longer ship.

If you arrived here looking for install instructions: Coral is now a Go application. Do not run pip install agent-coral — that installs the retired Python version, which shares command names, the ~/.coral data directory and port 8420 with current Coral. If you already ran it, remove it with pip uninstall agent-coral before installing.
