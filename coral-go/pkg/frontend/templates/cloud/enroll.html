Connect a server

On the machine you want to connect, open Coral → Settings → Connect to Coral Hub. It shows a code like ABCD-2345. Enter it here.

A machine is asking to connect to your account. Check that this is you:

Only approve a machine you control. Approving lets that machine appear in your account, and lets you (and anyone signed in as you) open its terminals and files from the web.

Connected. Your server will show up in the dashboard within a few seconds.
